## Question - 01

$$G(s)H(s) = \frac{e^{-0.1s}}{s} \text{ Calculate } \omega_{pc} = ?$$

$$G(j\omega)H(j\omega) = \frac{e^{-j0.1\omega}}{j\omega}$$

$$\phi = -0.1\omega - \pi/2$$

$$\text{at } \omega_{pc} \quad \phi = -\pi$$

$$-0.1\omega - \pi/2 = -\pi$$

$$0.1\omega = \pi/2$$

$$\omega = 5\pi \text{ rad/s}$$

$$M = 1/\omega = 1/5\pi$$

$$GM = 5\pi$$

$$GM(dB) = 20 \log 5\pi \text{ dB}$$
