## Question-08

The forward path transfer function of a unity feedback system is given by

$$G(s) = \frac{1}{(1+s)^2}$$

What is the phase margin for this system?

(A) $-\pi$ rad

(B) 0 rad

(C) $\pi/2$ rad

(D) $\pi$ rad

$$G(j\omega) = \frac{1}{(1+j\omega)^2}$$

$$\phi = -2\tan^{-1}\omega$$

$$M = \frac{1}{1+\omega^2}$$

$$\omega_{gc}: M = 1$$

$$\omega_{gc} = 0$$

$$\phi = 0 \quad PM = 180 + \phi$$
$$= 180^\circ = \pi\text{ rad}$$
